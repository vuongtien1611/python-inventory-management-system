# Tài liệu dự án (`docs/`)

Thư mục này lưu trữ toàn bộ tài liệu kỹ thuật, sơ đồ thiết kế và báo cáo của bài tập lớn **Chủ đề 04 – Quản lý kho sản phẩm bằng Python OOP**.

## Cấu trúc thư mục tài liệu

- [`uml/`](uml/): Lưu UML Class Diagram thể hiện mối quan hệ giữa các lớp (`Product`, `FoodProduct`, `ElectronicProduct`, `Supplier`, `StockTransaction`, `InventoryManager`, `StockService`, `ReportService`).
- [`flowcharts/`](flowcharts/): Lưu lưu đồ hoạt động (flowchart) của các nghiệp vụ chính và luồng điều hướng menu Console.
- [`screenshots/`](screenshots/): Lưu ảnh chụp màn hình minh họa quá trình chạy thực tế các chức năng của chương trình.
- [`reports/`](reports/): Lưu báo cáo bài tập lớn và bảng tổng hợp kết quả kiểm thử (test cases).

> **Lưu ý:** Các thư mục con hiện đang ở trạng thái khởi tạo (sử dụng `.gitkeep`) và sẽ được bổ sung dần trong quá trình nhóm thực hiện.
