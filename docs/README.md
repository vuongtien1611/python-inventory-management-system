# Tài liệu dự án (`docs/`)

Thư mục này lưu trữ toàn bộ tài liệu kỹ thuật, hợp đồng tích hợp, sơ đồ thiết kế và báo cáo của bài tập lớn **Chủ đề 04 – Quản lý kho sản phẩm bằng Python OOP**.

## Cấu trúc thư mục tài liệu

- [`API_CONTRACT.md`](API_CONTRACT.md): Bản **đề xuất hợp đồng API** thống nhất giao tiếp giữa `cli/`, `services/`, `models/` và `storage/` (đang chờ 5 thành viên xác nhận).
- [`uml/`](uml/): Lưu UML Class Diagram thể hiện mối quan hệ giữa các lớp (`Product`, `FoodProduct`, `ElectronicProduct`, `Supplier`, `StockTransaction`, `InventoryManager`, `StockService`, `ReportService`).
- [`flowcharts/`](flowcharts/): Lưu lưu đồ hoạt động và kiến trúc tổng quan, hiện đã có [`main_menu_flowchart.md`](flowcharts/main_menu_flowchart.md).
- [`screenshots/`](screenshots/): Lưu ảnh chụp màn hình minh họa quá trình chạy thực tế các chức năng của chương trình.
- [`reports/`](reports/): Lưu báo cáo bài tập lớn và bảng tổng hợp kết quả kiểm thử (test cases).
